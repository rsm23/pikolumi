# Reviewer instructions — draft, not submitted

Pikolumi is an offline educational app with a complete bundled catalog of 2,400 activities in 16 sections. All activities are accessible immediately; stickers and progress do not lock content. There are no purchases, subscriptions, accounts or app-owned analytics. Profiles use avatars and generated labels only.

1. Launch the app, open Coloring, and select a page. Fill or draw, leave the activity and reopen it to see the saved artwork. The gallery also resumes saved pages.
2. Open Counting, Letters, Memory, Maze or Music from the main library. Instructions can be replayed using the speaker button. Math notation keeps its intended direction in Arabic.
3. Open the lock icon for the parent area. On a fresh install, complete the adult multiplication challenge, then choose and confirm a six-digit PIN. There is no fixed reviewer PIN; reviewers set their own. Existing parent controls require that PIN. Repeated wrong attempts cause a persisted temporary lockout.
4. Within the parent area, choose English, French, Spanish, Brazilian Portuguese or Arabic, select difficulty, add an avatar profile, inspect progress, control sound/motion, open supported privacy choices or export artwork. Returning from background locks the parent session.
5. Install while online, then enable airplane mode: activities, illustrations, essential guidance and saved results do not need a connection. Ads may be unavailable; this never prevents access.

Production advertising is not enabled in the current QA packages. Google test ads appear only on library screens or after eligible completions. Frequency accounting is global across sibling profiles and launches: five foreground minutes, four completed activities, five foreground minutes between interstitials and at most six per rolling hour. Activity engines cannot request ads. Failed ad loads do not block navigation.

**Do not submit these notes or QA binaries as a production review package.** Before submission, replace this paragraph with verified distribution build numbers, published support/privacy URLs, complete ad disclosures and evidence resolving all release gates. Apple Kids advertising evidence is currently insufficient; the iOS release is held. Detailed curriculum and narration review, physical-device QA and asset-rights review remain outstanding.
