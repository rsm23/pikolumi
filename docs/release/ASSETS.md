# Asset provenance and rights review

## Original visual assets

- `assets/content/art.json`: 456 original vector scenes/motifs compiled from `scripts/illustrations.py` and `scripts/build_content.py`. No downloaded illustration pack is included. Coordinates, closed regions and region IDs are authored in this repository.
- `assets/art/piko.png`: original generated Piko mascot, created for this project with the built-in image generation tool on 2026-10-11. Direction: a joyful turquoise bird, yellow belly, lilac feather tuft, coral crayon and transparent background; no existing branded character reference.
- `assets/art/app-icon.png`: original icon treatment derived from that Piko image with a warm cream background and no lettering. Native icon exports are generated by `scripts/export_icons.py`.
- `assets/audio/note_0.mp3` through `note_7.mp3`: original sine-wave/harmonic tones synthesized in the audio build script; no sampled instrument recording.

Generated visuals still require a final human illustration/appropriateness review before launch. The original generation outputs are retained outside the repository in the current Codex task's generated-images directory.

## Fonts

Nunito and Noto Sans Arabic are bundled under the SIL Open Font License. Their license texts are included beside the fonts under `assets/fonts/`. Source: Google Fonts official repositories. No system font files were copied into the app.

## Narration: development assets, release gate open

Narration is generated offline at build time with Piper. The app bundles compressed MP3 recordings, not the voice models or Piper runtime. Voice model cards downloaded from the official `rhasspy/piper-voices` repository are archived in this directory.

| Locale | Model/data source | Recorded rights evidence | Release status |
|---|---|---|---|
| English | LJSpeech high / LJ Speech dataset | Model card: public-domain dataset, trained from scratch | Native pronunciation review pending |
| French | SIWIS medium / SIWIS dataset | Model card: CC BY 4.0; fine-tuned from Lessac | Attribution and base-model rights review pending |
| Spanish | Sharvard medium / Harvard-style Spanish sentences | Model card: CC BY 3.0; fine-tuned from Lessac | Attribution and base-model rights review pending |
| Portuguese | Faber medium | Model card: CC0; fine-tuned from Lessac | Base-model rights and native pronunciation review pending |
| Arabic | Kareem medium / ArabicTTS | Model card says only “See URL”; linked corpus has no established commercial license in the evidence collected | **Commercial redistribution rights not established; public release held** |

Sources and author attribution must be finalized before shipping. Do not treat a dataset license as complete proof of model/output rights, and do not publish the Arabic narration with the current unresolved evidence. Replace affected narration with recordings having explicit redistribution permission if rights cannot be established. Arabic essential script is Modern Standard Arabic, but the selected development model is tagged ar_JO; a native speaker must check pronunciation and register. Spoken letter names are included; a comprehensive phoneme curriculum is not yet educator-approved.
