# Asset provenance and rights review

## Original visual assets

- `assets/content/art.json`: 576 original vector scenes/motifs compiled from `scripts/illustrations.py` and `scripts/build_content.py`. No downloaded illustration pack is included. Coordinates, closed regions and region IDs are authored in this repository.
- `assets/content/art_legacy_v2.json`: original revision 2 geometry retained exclusively for existing saved artwork and puzzle resumes. It does not add advertised activities.
- `assets/art/piko.png`: original generated Piko mascot, created for this project with the built-in image generation tool on 2026-10-11. Direction: a joyful turquoise bird, yellow belly, lilac feather tuft, coral crayon and transparent background; no existing branded character reference.
- `assets/art/piko_3d/`: original Blender-rendered 3D animation, authored locally on 2026-10-12 following that mascot identity. No imported meshes, textures, motion capture or paid generation services were used. Editable sources and rebuilding instructions are in `art_source/piko/`; the bundled manifest records source/frame-sheet hashes and dimensions. The static mascot and store icon remain available. This adds no third-party asset dependency; owner review completion is recorded in `../qa/owner-language-review-completion.json`.
- `assets/art/app-icon.png`: original icon treatment derived from that Piko image with a warm cream background and no lettering. Native icon exports are generated by `scripts/export_icons.py`.
- `assets/audio/note_0.mp3` through `note_7.mp3`: original sine-wave/harmonic tones synthesized in the audio build script; no sampled instrument recording.

The owner confirmed completion of the five-language content review on 2026-10-13. The original generation outputs are retained outside the repository in the current Codex task's generated-images directory.

## Narration: commercial sources and owner review

Catalog revision 2 replaces **every** previous Piper recording. Only compressed MP3s ship; no speech model, Python runtime or online generator is in the application. No Apple system voice or downloaded human reference recording is used.

SILMA's reference is a fixed, newly synthesized Kokoro `af_heart` sentence. It is not a person's recording, custom speaker clone, or a bundled SILMA demonstration sample. Its reference text and waveform digest are recorded. Arabic synthesis consumes an explicitly vowelled finite script directly through the character model, avoiding a phonemizer that merges emphatic consonants. This is a technical improvement, **not** native pronunciation approval.

Pinned model revisions, model/config/voice hashes, synthesis settings, script text, seed, and output SHA-256 for each recording are in `assets/content/audio_provenance.json`. The compiler verifies its cache against the synthesis input and existing output. The catalog validator checks every recording's script/hash against that provenance; a missing locale or stale recording fails validation.

On 2026-10-12, all 648 speech clips and 8 original note tones passed silent MP3 decoding, mono/24 kHz, finite-sample, duration and level checks. Lossy encoding produced excess peak level in Arabic `letter_13.mp3`; linear attenuation repaired it, with the original/output hashes, gain and mastering-script hash retained in the provenance. The exact compiler/mastering sources are archived by SHA-256 under `voice-licenses/generators/`. The new source permissions and bundled attributions clear the asset-rights release gate; pronunciation and illustration/editorial review are separate from source permissions; owner review completion is now recorded.

Published model cards and license texts are retained in `voice-licenses/`. `assets/content/CREDITS.txt` contains the source acknowledgements, Apache/MIT notices, original font license texts, and SIWIS/Koniwa attribution. Parents can view it offline through **Credits & licenses**. SIWIS attribution follows the [University of Edinburgh source record](https://doi.org/10.7488/ds/1705), CC BY 4.0. These notices identify synthesized output as modified material; source authors do not endorse the app.

The previous Piper/Lessac/Kareem evidence is archived under `voice-licenses/legacy-piper/` for audit history. Lessac's published [research license](https://www.cstr.ed.ac.uk/projects/blizzard/2013/lessac_blizzard2013/license.html) and the missing Kareem corpus grant were not used as commercial clearance. Nabra was investigated but not selected because its published phoneme cleanup removes emphasis markers important to Arabic literacy.

The owner confirmed completion of the five-language content/pronunciation review on 2026-10-13. See `../qa/owner-language-review-completion.json` for that aggregate attestation and the snapshot hashes. The 55 flagged Arabic corrections have separate hash-bound acceptance receipts; these do not invent individual receipts for the other clips. Future new recordings need review before promotion. Model licensing alone does not certify educational quality.
