## Integration cleanup

Flutter integration tests default to uninstalling their initial application package at teardown. With an optional Android QA suffix, the initial package reference came from an earlier APK, while the test itself installed the new `.qa` package. Cleanup removed the earlier test installation and left `.qa` installed. The original normal entry-point QA app is restored afterward. Use `--no-uninstall` for native `flutter test` and `--keep-app-running` for `flutter drive` runs on user devices; do not rely on a suffix alone to protect an existing install. The dedicated offline script now sets this option and refuses to clear an existing QA package.
