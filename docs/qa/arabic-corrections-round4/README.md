# Arabic replacements: fourth review round

Round three approved ظِ and هَ; both are now bundled, for 54 approved replacements. صِ (`syllable_37.mp3`) remains rejected. The fourth-round take was also rejected with the note “the sound should be like Si”. This page retains that imported decision; [round 5](../arabic-corrections-round5/index.html) provides a new contextual attempt. Select **Sounds correct** or **Still wrong**, then **Save review**. Unapproved audio remains outside bundled app assets.

This direct Modern Standard Arabic take uses a new seed, a 1.00-second generation window and synthetic reference clips: approved elephant/handwriting/صُ clips plus the existing صَ clip. No human speaker clone, paid provider or audible testing was used. Exact source/model/reference hashes, text and seed are recorded in `candidates.json` and its archived generation source.

`validation.json` checks finite, non-silent mono 24 kHz audio, changed hashes and source bindings. `review-ui-validation.json` checks the single-card selection, filters, browser storage, export and stale-approval handling, with two explicit player controls and no playback/network calls. These checks do not approve pronunciation. Stores remain on hold.
