# Memory turns and playful Piko, 2026-10-12

Memory cards turn over in 420 ms with cubic easing, perspective, edge shading and a projected shadow. The face changes halfway through, with counter-rotation to keep pictures readable. The press splash/highlight is disabled so the turning card leaves no flat gray plate behind it. Restored matched cards begin face up. A mismatch stays visible for 1,300 ms from the second tap, then turns back; the board rejects additional taps until concealment finishes. Matches resolve after 650 ms, preserving existing saved indices, deck seeds and completion behavior. Reduced motion and accessibility navigation change faces immediately.

Piko responds to taps in the library, activity header and completion dialog. Ten distinct two-second Blender clips provide a wave, wink, nod, bow, wiggle, stretch, crayon flourish, curious glance, wing flutter and two small hops. A shuffled bag uses every reaction before repeating and avoids an immediate repeat between cycles. Rapid taps do not interrupt a reaction. Completion can replace a reaction with its reward animation; a tapped dialog reaction returns to the held reward pose. Reactions remain silent and never report activity completions, request ads or write preferences.

In the library, Piko occasionally shows an invitation above its head: first after 24 seconds of available idle time, then 45–75 seconds after the previous six-second bubble disappears. Messages invite coloring, matching, puzzles, counting or drawing and use the interface language, independently of the selected learning language. Text is measured in the active font and text scale, reserving enough space without shifting the section controls when bubbles appear. Invitations pause offstage/inactive, disappear during a tap reaction and reset when language changes. Automatic invitations are disabled for reduced motion/accessibility; a deliberate tap can show a static invitation instead. Activity headers keep their question/navigation area clear of bubbles.

The original icon/splash face, swept crest, feathers, proportions and crayon remain on the articulated painted 3D relief. All twelve clips (780 frames) are bundled offline. Reactions load on demand in shared 128-pixel atlases and release their textures when unused. Idle and reward retain their 128/192-pixel frames. The combined atlas bytes would decode to 59.5 MiB if all clips were loaded simultaneously; normal navigation requires at most 23.5 MiB for idle, reward and one reaction. The package does not preload the whole collection. Source meshes and texture bindings pass `model-validation.json`; transparent framing, unique poses, clip/source hashes and texture sizes pass `asset-validation.json`.
