# Arabic Trace & Write corrections — 2026-10-13

All 80 language-specific Arabic tracing configurations were corrected: 28 isolated letters, 27 letters with fatḥa, long alif (آ), and 24 words. The remaining 80 numeral/motor activities, all non-Arabic lesson data, activity IDs, completed results, 54 approved Arabic recordings and mascot assets are unchanged.

The former nine-vertex ج/ح/خ guide had an angular, misleading head/bowl. ط/ظ started by drawing the ascender upward. Word placement compressed x by the character count while scaling y independently; the aspect ratio of و in ورد was only 0.323 versus 0.833 alone. Regression checks failed on the old bundled catalog for the reversed ascender, distorted proportions and missing body/dot/vowel order.

`scripts/arabic_handwriting.py` now authors smooth cubic centre lines with natural letter advances, a shared baseline and uniform fit. Bodies are ordered by reading position, with explicit pen lifts for stems and loops, followed by dots and any vowel mark. ط/ظ have the oval/base first and a separate top-to-bottom stem; ه and م use clockwise loop formation. The ج family has a short horizontal head and a curved bowl rather than the previous zigzag. Six right-joining-only letters correctly break connection to the following letter; words such as ورد and درس therefore retain natural pen lifts. Word strokes and dots scale together, keeping counters and dots distinct.

The lesson's written model and practice board share the exact same paths. The model is a vector preview with the target glyph as its accessibility label. Rendering and touch input use one uniform viewport transform even if a board is rectangular; guide widths scale with the lettering. Essential guide/finished-ink contrast is increased, and the static model has a repaint boundary.

For formation checks, consulted the [Alkhattat / Ibn Khaldun Schools Naskh booklet](https://alkhattat.net/Calligraphy_booklets/Naskh_Kids-Booklet_Alkhattat.pdf), including its letter-direction diagrams. These are independently authored motor guides; the worksheet illustrations and font outlines are not bundled or copied. Automated checks and visual inspection are not native-educator signoff.

Geometry revision 3 also retains the first corrected revision (2), so unchanged revision-2 paths restore exactly and refined loop paths migrate by progress. Old incomplete Arabic stroke checkpoints are converted by overall path progress to the corrected guide's pen lifts, retaining the previous stroke/index in `traceMigration` on the next save. Revised checkpoints restore exactly. Completed results are unchanged; no installation clears or resets user data. Legacy geometry remains only as migration data, never as the displayed guide. Save occurs before the completion callback so completion cleanup cannot race the last tracing checkpoint.
